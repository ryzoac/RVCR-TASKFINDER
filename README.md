# RVCR TASKFINDER

### Plataporma para sa mga Mag-aaral ng Pag-aaral ng Kasaysayan sa Lipunang Pilipino

## Tungkol sa Proyekto

Ang RVCR TASKFINDER ay isang web-based platform na naglalayong tulungan ang mga mag-aaral na madaling makahanap, makakita, at makapagbahagi ng mga Performance Task para sa asignaturang Pag-aaral ng Kasaysayan sa Lipunang Pilipino.

## Mga Pangunahing Tampok

- **Maghanap ng Gawain** – Maghanap ng Performance Tasks gamit ang search bar.
- **Mga Kategorya** – Ayusin ang mga gawain ayon sa kanilang uri.
- **Magdagdag ng Gawain** – Magdagdag ng bagong Performance Task.
- **Tingnan ang Detalye** – Basahin ang mga paglalarawan at panuto ng bawat gawain.
- **Burahin ang Gawain** – Alisin ang mga gawaing hindi na kailangan.
